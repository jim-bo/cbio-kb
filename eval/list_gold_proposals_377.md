## Cross-cutting decision for the user
The "focus / not-incidental" questions (LS01, LS05, LS06, LS09) and the dataset/method
questions (LS04, LS07) all hinge on **strict (precision) vs permissive (recall)** criterion
reading. Since these are *list* questions whose metric is retrieval **recall**, the
comprehensive (permissive) set is arguably the semantically-correct gold — but it makes the
questions much harder and 124-paper golds (LS01) dominate scoring. Need the user's stance.
